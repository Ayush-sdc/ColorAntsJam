# Color Slither Jam — All Reconstructable Prefabs (Slither Excluded)
Source: user-supplied iOS Unity player build, Unity 2022.3.37f1.
**Reconstructed prefab roots: 73** (21 game/shared prefabs + 52 resource/UI/debug prefabs).
**Explicitly excluded:** `Head Snake`, `Mid Snake`, `Tail Snake`. No reconstructed slither prefab is present.
## Use in Unity
1. Copy `Assets/ColorSlitherJamAllPrefabs` into your Unity project.
2. Let OBJ files import.
3. Run **Tools > Color Slither Jam > Build ALL Extracted Prefabs (No Slither)**.
4. Generated prefabs appear under `Assets/ColorSlitherJamAllPrefabs/Prefabs/Reconstructed/`.
## Important limitation
A compiled player build does not retain the original loose `.prefab` YAML/source project. These are reconstructed from serialized GameObject roots. Transform/RectTransform hierarchy and parseable 3D MeshFilter/MeshRenderer dependencies are restored. Many original MonoBehaviour, UI Image/Button/TMP bindings, particle settings, and proprietary shader behavior cannot be losslessly recreated because TypeTrees/scripts are stripped. Their exact raw serialized component payloads are included under `RawSerialized/` for later forensic parsing.
